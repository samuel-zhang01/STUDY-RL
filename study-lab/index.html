01 / Weeks 1–2 → revisit in week 7

A reward now, or a reward later?

Stopping pays 2 immediately. Continuing pays 0, then a final reward one step later. Predict: if you care less about the future, which choice becomes better?

0 values only the immediate reward; 1 counts both equally in this finite task.

Why is the policy gradient not zero when advantages average to zero?

The two action scores differ. If p = sigmoid(z), continue has score 1−p and stop has score −p. Their advantage-weighted sum is p(1−p)(Qcontinue−Qstop). The displayed derivative is with respect to z. At exact p=0 or 1 we display its limit; a finite sigmoid logit never reaches those endpoints.

02 / Weeks 3–4 → revisit in week 8

The data stopped. Did the task?

For one observed transition, the current value estimate is 1 and the learning rate α is 0.5. Predict: should an external rollout cutoff erase the future?

A time limit built into the task's objective is termination. An external collection limit is truncation. For finite-horizon decisions, include remaining time in the state. At a reset, never bootstrap from the next episode's initial observation.

Which side goes flat?

04 / Week 11 → revisit in week 14

A large weight cannot invent evidence.

We observe only the reward of each chosen action. In this teaching fixture, an observed A pays 1 and an observed B pays 4. Predict: can you evaluate “always B” if your logger never chooses B?

The log stays fixed as you change probabilities. This is sensitivity analysis, not a new random sample. We flag impossible logs.

What do IPS, SNIPS and effective sample size tell me?

IPS divides the sum of weighted rewards by the number of logged rows. SNIPS divides it by the sum of weights, which must be nonzero. Weight-based effective sample size is (sum w)² / sum(w²); it diagnoses weight concentration, not a confidence interval. A single B row may carry the whole estimate. Neither normalisation repairs absent support or data used to select the target policy.
