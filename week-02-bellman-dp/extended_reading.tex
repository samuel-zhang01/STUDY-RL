\section*{Read with a question in mind}
Start with the week's teaching guide and its small worked example. Then use
these readings to connect the algorithm to its assumptions and evidence.
The explanations and investigations below are course commentary, not
quotations. Read the source before reusing a theorem or a reported result.
For each paper, record the objective, observation model, claimed result,
conditions and one condition your local experiment does not reproduce.

\section*{1. Bellman (1957): Dynamic Programming}
\textbf{Primary source or book record:} \url{https://press.princeton.edu/books/paperback/9780691146683/dynamic-programming}.

\paragraph{What to learn.} The principle of optimality decomposes a decision sequence into its immediate consequence and an optimal continuation. This is the conceptual starting point for Bellman backups.

\paragraph{What the result requires.} The state must retain what is needed to predict rewards and transitions. A history-dependent problem may need an augmented state before the recursion is valid. Finite-horizon values also depend on remaining time.

\paragraph{Notebook investigation.} Use \texttt{exercise\_1\_bellman\_operator}. With one action, reward 2, successor value 3 and discount 0.9, a backup gives 4.7. Identify which quantity is an input estimate and which is an environment property.

\section*{2. Howard (1960): Dynamic Programming and Markov Processes}
\textbf{Primary source or book record:} \url{https://books.google.com/books?id=fXJEAAAAIAAJ}.

\paragraph{What to learn.} Policy iteration alternates evaluation of a fixed policy and greedy improvement. Reading the two stages separately prevents confusion between evaluating a policy and solving the control problem.

\paragraph{What the result requires.} For a finite discounted MDP, exact evaluation and consistent tie handling support termination. There is no general guarantee that policy iteration requires only logarithmically many improvement steps. This catalog link identifies the book; it is not a page-level proof source.

\paragraph{Notebook investigation.} Compare \texttt{exercise\_3\_policy\_iteration} with \texttt{exercise\_6\_policy\_evaluation\_closed\_form}. Check $(I-\gamma P_\pi)V=r_\pi$ before interpreting a policy switch.

\section*{3. Puterman (1994): Markov Decision Processes}
\textbf{Primary source or book record:} \url{https://onlinelibrary.wiley.com/doi/book/10.1002/9780470316887}.

\paragraph{What to learn.} Provides a systematic treatment of finite-state decision processes. Use the discounted chapters to follow contraction, existence of optimal stationary policies and evaluation/improvement arguments.

\paragraph{What the result requires.} Average-reward, undiscounted episodic and discounted results have different hypotheses. A theorem for finite discounted models cannot be transferred to arbitrary neural approximation by changing the symbols.

\paragraph{Notebook investigation.} Derive $\|V_k-V^*\|_\infty\le\gamma^k\|V_0-V^*\|_\infty$. Use \texttt{exercise\_5\_contraction\_factor} to check an upper bound, not demand equality at each sweep.

\section*{4. Tsitsiklis and Van Roy (1997): An Analysis of Temporal-Difference Learning with Function Approximation}
\textbf{Primary source or book record:} \url{https://web.mit.edu/~jnt/www/Papers/J063-97-bvr-td.pdf}.

\paragraph{What to learn.} Analyses linear TD under specified on-policy sampling and stochastic-approximation conditions. The limit solves a projected Bellman equation involving a stationary-distribution-weighted $L_2$ projection.

\paragraph{What the result requires.} The TD fixed point is generally not the orthogonal projection of the true value function. The relevant projection argument is not a weighted sup-norm contraction. Off-policy sampling and nonlinear approximation need separate analysis.

\paragraph{Notebook investigation.} For feature matrix $\Phi$, distinguish $\Pi V^\pi$ from the solution to $v=\Pi T^\pi v$. Explain why changing the sampling weights changes the projection geometry.

\section*{5. Munos and Szepesvari (2008): Finite-Time Bounds for Fitted Value Iteration}
\textbf{Primary source or book record:} \url{https://jmlr.org/papers/v9/munos08a.html}.

\paragraph{What to learn.} Studies sampling-based fitted value iteration with a generative model, separating statistical approximation and error propagation. The analysis includes inherent Bellman error and concentrability of future state distributions.

\paragraph{What the result requires.} A small regression error on one sampling distribution does not automatically imply small control error under a different occupancy. The bounds are not a plug-in convergence theorem for the local deep-Q implementation.

\paragraph{Notebook investigation.} Sketch a distribution that samples one state frequently and misses a valuable reachable state. Explain why more samples from the same distribution may leave the relevant approximation failure unresolved.

\section*{Synthesis: evidence you should be able to show}
\begin{enumerate}
\item Reproduce one numerical calculation before running a long experiment.
\item Name the precise objective, sampling distribution and terminal convention.
\item Compare the local implementation with one source: list a shared mechanism
and one simplification that prevents calling it a full reproduction.
\item Separate an algebraic identity, an assumption-dependent theorem and an
empirical result. A plot alone does not prove a theorem.
\item Save the notebook with seed, parameters, axes, denominators and a short
explanation of an unexpected result. Keep evaluation data separate from tuning.
\end{enumerate}
Return to the teaching guide's notebook investigation for the local function
names, expected checks and interpretation questions. Source code and notebooks
are available together in the course repository; the web reader is the entry
point and the downloaded notebook is the execution workspace.
