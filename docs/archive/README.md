# Historical validation records

These files record earlier teaching reviews and validation runs. They are kept
for context; their test counts and execution claims apply to the revisions and
environments described in them. The weekly directory names and links were
updated during public-release preparation.

Fresh generated reports go into the ignored `reports/` directory. See
[the release review](../RELEASE_REVIEW.md) for the latest release-preparation
checks and [the README](../../README.md) for commands you can rerun.
